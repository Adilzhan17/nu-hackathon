# Forte Vision — визуальная система

Рабочее место специалиста, который проверяет кассовые операции по видео. Главная задача — сопоставить наблюдение, таймкод и кадр, сохранив различие между гипотезой модели и решением человека.

Направление задано ТЗ: спокойный корпоративный интерфейс, тёмная navy-навигация, светлая рабочая область, сдержанные карточки. Цвет действия — бордовый. Янтарный обозначает необходимость проверки, зелёный — отсутствие отмеченных признаков. Это прототип для кейса ForteBank, не утверждённый банковский брендбук.

- Manrope Variable с кириллицей, локально через Fontsource. Моноширинность используется только для измеряемых значений через tabular-nums.
- Navy `#151e2e`, холст `#f6f7f9`, белые панели, акцент `#a41d48`.
- Основной экран: видео и кадры слева, вердикт и события справа; на узких экранах видео, события и кадры следуют вертикально.
- Без выдуманных KPI, процентов обработки, нормативных ссылок и заявлений о запущенной модели.
- Демосценарии обозначены на уровне страницы, вердикта и кадров.
- Клавиатурная навигация, видимый focus, skip link, live regions, Radix Dialog с удержанием фокуса и Escape. Анимация учитывает reduced motion.
- Графика — собственная геометрическая схема процесса и кассовой зоны. Никаких кадров реальных людей или приватных видео.

Рекомендации изучены в [Impeccable](https://github.com/pbakaus/impeccable), [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), [Taste Skill: Minimalist UI](https://github.com/Leonxlnx/taste-skill/blob/main/skills/minimalist-skill/SKILL.md). Взяты принципы иерархии, отступов, состояний и сдержанной палитры. При конфликте приоритет у ТЗ: например, использованы требуемые Lucide, а не альтернативная библиотека из Taste Skill. Готовые сторонние dashboard-шаблоны не копировались.
