# Референсы для выбора алгоритма

Подборка первичных источников от 17 октября 2026 года. Ни один подход пока не выбран, модели и датасеты не скачивались. Это материалы для исследования компонентов, а не готовое решение для подачи на хакатон.

## Близкие задачи

| Работа | Что можно изучить | Отличие и условия использования |
| --- | --- | --- |
| [MERL Shopping, CVPR 2016](https://www.merl.com/research/highlights/merl-shopping-dataset) | 106 роликов примерно по 2 минуты с верхней камеры; действия рук и взаимодействия с предметами; объединение признаков сцены и человека во времени | Магазин, не банковская касса. Данные предлагаются для исследований; коммерческое разрешение нельзя предполагать |
| [RetailAction, Standard AI, ICCV Workshop 2025](https://huggingface.co/datasets/standard-cognition/RetailAction) | Действия take/put/touch, место взаимодействия и временной интервал; выбор кадров по движению | Несколько синхронных камер отличаются от смены одной камеры в финале. [Собственная лицензия](https://huggingface.co/datasets/standard-cognition/RetailAction/blob/main/LICENSE): атрибуция, обезличенность; при выручке связанных продуктов/услуг свыше $10 000 требуется отдельная лицензия |

## Компоненты для экспериментов

| Работа | Применимость | Ограничение |
| --- | --- | --- |
| [RTFM, ICCV 2021](https://arxiv.org/abs/2101.10030), [официальный код](https://github.com/tianyu0207/RTFM) | Поиск подозрительных фрагментов при слабой разметке «норма/аномалия» на уровне видео | Не даёт банковское правило и объяснение. Явная лицензия кода при проверке не найдена: пока только исследовательский референс |
| [ActionFormer, ECCV 2022](https://github.com/happyharrycn/actionformer_release) | Устройство временного детектора: начало, конец и класс события | Штатное обучение требует классов и интервалов; имеющихся бинарных меток с точкой времени недостаточно. [Код MIT](https://github.com/happyharrycn/actionformer_release/blob/main/LICENSE), условия внешних данных/весов проверяются отдельно |
| [Qwen2.5-VL-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct) | Локальное описание видео/кадров с временной привязкой; возможная проверка уже выделенного короткого фрагмента | Для конкретной версии 7B указана Apache-2.0. Это не банковский детектор; точность, память и скорость на оборудовании команды ещё не измерены |

## Выводы для будущих экспериментов

Следующие пункты — предложения для проверки, а не доказанная эффективность на кейсе ForteBank:

- Изучать последовательности действий и взаимодействия рук с предметами: один кадр может не показывать порядок процедуры.
- Разделить выделение подозрительного интервала, сохранение реальных кадров и объяснение по проверенному справочнику правил. Источник и пункт правила не должны появляться только из свободного ответа модели.
- Использовать исходные временные метки видео для выдачи кадров, а не считать время только как номер кадра / предполагаемый FPS.
- Проверять перенос на другой ракурс отдельно. Кадры одного ролика не распределять между обучающей и проверочной выборкой.
- На небольшом датасете сравнить несколько простых прототипов, измеряя вердикт, локализацию и общее время обработки. Эти источники не доказывают достижимость лимита 5 минут на нашем оборудовании.

Перед использованием кода, весов или данных нужно проверить условия конкретного артефакта. Лицензия репозитория не обязательно покрывает веса и обучающие датасеты. Ограничение кейса на готовые решения отмечено в [requirements.md](requirements.md).
