Старые remote-ветки не удалены и не переписаны. feat/frontend остаётся прежним

ветки других участников в рамках одного рефакторинга не требуется.

Рекомендуемая схема дальнейшей работы:
  feat/<область>-<задача>       добавление функциональности
  fix/<область>-<ошибка>        исправление
  refactor/<область>           изменение устройства без смены поведения
  release/<версия>             зафиксированная проверенная версия

Области: web, api, analysis, training, regulations, deployment.
Ветка описывает изменение, а не имя разработчика или один старый каталог.
Не создавать отдельную постоянную ветку для каждой модели или каждого слоя.

Сравнить актуальные вершины и расхождение без изменений репозитория:
  python scripts/inspect_branches.py
  python scripts/inspect_branches.py --json

Возврат к a113284 — только после завершения активных заданий и с учётом
deploy/README.txt. Переключение ветки само по себе не переключает уже запущенный
Python-процесс и не откатывает код, скопированный на GPU-хост.
